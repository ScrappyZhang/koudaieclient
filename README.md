# 代理人客户资源页原型

这是一个保险代理人客户管理系统的前端原型，使用 React + Vite + TypeScript + TailwindCSS 构建。

## 本地运行

**前置条件:** Node.js 18+

1. 安装依赖：
   ```bash
   npm install
   ```

2. 启动开发服务器：
   ```bash
   npm run dev
   ```

3. 浏览器打开 http://localhost:3000

## 功能说明

- **首页**: 展示今日日程、AI智能建议、功能金刚区
- **客户管理**: 客户分布矩阵、客户动态、客户质量分析
- **咨询**: 本地模拟的 AI 对话功能（无需 API Key）
- **我的**: 代理人个人资料页面

## 技术栈

- React 19
- Vite 6
- TypeScript 5.8
- TailwindCSS 4
- Motion (动画库)
- Lucide React (图标库)
